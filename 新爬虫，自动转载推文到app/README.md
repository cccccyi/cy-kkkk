# Twitter推文监听工具

一个使用Playwright开发的Twitter推文监听工具，可以实时监听指定用户的推文并将数据存储到MySQL数据库中。

## 功能特点

- ✅ 监听指定Twitter用户的推文
- ✅ 随机时间刷新（默认5-10秒）
- ✅ 数据存储到MySQL数据库
- ✅ 浏览器窗口可见，便于观察和调试
- ✅ 支持登录状态保持
- ✅ 配置灵活，可自定义刷新时间等参数

## 环境要求

- Node.js >= 14.x
- npm >= 6.x
- MySQL >= 5.7

## 安装步骤

1. 克隆或下载项目到本地

2. 安装依赖包：
   ```bash
   npm install
   ```

3. 安装Playwright浏览器：
   ```bash
   npx playwright install
   ```

4. 创建本地环境配置并填写数据库连接：
   ```bash
   cp .env.example .env
   ```
   - 确保MySQL服务已启动
   - 创建数据库（如果不存在）：`CREATE DATABASE autox;`
   - 导入表结构：`mysql -u root -p autox < autox.sql`
   - 修改`.env`文件中的数据库配置；不要将该文件提交到 Git
   - 为 `API_AUTH_TOKEN` 生成至少 32 字符的随机值；所有 `/api` 请求都必须携带 `Authorization: Bearer <token>`
   - `CORS_ORIGINS` 使用逗号分隔可信前端来源；不配置时不允许浏览器跨域
   - 默认只监听 `127.0.0.1`。如需由反向代理或容器访问，显式设置 `HOST`，并在边界层限制访问

## 使用方法

### 1. 登录Twitter

由于Twitter需要登录才能访问推文，您需要先使用登录脚本完成登录：

```bash
npm run login
```

执行后会打开浏览器窗口，请手动完成Twitter登录操作。登录成功后，按Enter键保存会话状态。

### 2. 开始监听推文

登录完成后，执行以下命令开始监听指定用户的推文：

```bash
npm start
```

工具会自动打开浏览器，访问指定用户的主页，并开始监听推文。

## 配置选项

您可以在`index.js`文件中修改以下配置参数：

| 参数名 | 说明 | 默认值 |
|--------|------|--------|
| `targetUrl` | 监听的Twitter用户主页URL | `https://x.com/HashNewsHK` |
| `minRefreshTime` | 最小刷新时间（毫秒） | `5000` (5秒) |
| `maxRefreshTime` | 最大刷新时间（毫秒） | `10000` (10秒) |
| `status` | 存储到数据库的推文状态 | `1` (刚发现) |

## 数据存储

抓取的推文数据会存储到MySQL数据库的`twitter_tweets`表中，包含以下字段：

- `id`：数据库自增ID
- `url`：推文链接
- `user_id`：用户ID
- `username`：用户名
- `created_at`：推文发布时间
- `fetched_at`：数据抓取时间
- `status`：推文状态（1刚发现，2数据补充完整）

其他字段会保持为空，供后续功能扩展使用。

## 注意事项

1. **登录状态**：工具会自动检查登录状态，如果未登录会提示您先运行登录脚本。

2. **浏览器窗口**：工具运行时浏览器窗口会保持可见状态，便于观察和调试。

3. **刷新时间**：刷新时间是随机的，默认在5-10秒之间，可以在配置中修改。

4. **重复推文**：工具会自动过滤已处理的推文，避免重复存储到数据库。

5. **网络问题**：如果网络不稳定，工具会自动重试，确保数据抓取的连续性。

## 故障排除

1. **无法登录**：确保您的网络环境可以访问Twitter，并且输入的登录信息正确。

2. **数据库连接失败**：检查`.env`文件中的数据库配置是否正确，确保MySQL服务已启动。

3. **推文提取失败**：Twitter页面结构可能会变化，如果遇到这种情况，请更新推文提取的选择器。
