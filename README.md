# catdex
catdex on cat20

## 目录说明（已按功能重构）

该仓库原先的多个顶层目录已移动到更清晰的栏目下，便于你快速定位“抓取/转写/快讯/推送”链路与“DEX”类项目等。

- `news-pipeline（抓取-转写-推送）`：`AI快讯转写豆包版`、`TG推送豆包版`、`快讯转语音讯飞版`、`推特爬虫（模拟操作版）`、`新爬虫，自动转载推文到app`、`哈世链闻网站及app代码`
- `dex（DEX）`：`antSwap`、`catswap`、`launchpad`
- `crawlers（各类爬虫）`：`各类网站爬虫`
- `telegram（TG机器人）`：`tg活跃机器人`
- `app-media（推送-媒体-海报）`：`app推送服务`、`media-backend`、`海报生成器前端`
- `auto-reply（自动回复）`：`自动回复服务端`、`自动回复脚本，通过油猴在浏览器执行`
- `admin（资讯后台）`：`资讯管理后台前端`、`资讯管理后台后端`
- `private-message（私信系统）`：`新私信后端程序`、`新私信执行端，油猴脚本`
- `data（数据处理）`：`采集数据处理相关`
- `tools-jobs（脚本-任务-后端列表）`：`Backend-List`、`backend-server`、`php任务执行`
