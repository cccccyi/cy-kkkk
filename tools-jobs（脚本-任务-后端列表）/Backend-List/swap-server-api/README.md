## Description
[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

### 分为三个主要模块
- DEX Swap 接口
- DEX Swap 后端服
- Admin 管理端接口

## Installation

```bash
$ yarn install
```

## Running the app

```bash
# development
$ yarn run start

# watch mode
$ yarn run start:dev

# production mode
$ yarn run start:prod
```

## Test

```bash
# unit tests
$ yarn run test

# e2e tests
$ yarn run test:e2e

# test coverage
$ yarn run test:cov
```
